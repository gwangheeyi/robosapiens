# Mock 로봇 작업 관리 가이드

## 개요

`작업` 메뉴는 앱 Mock 로봇에게 목적지 이동 작업을 배정하고 진행 상태를
관리합니다. 현재 작업은 앱 내부 시뮬레이션용이며 RMF Dispatcher로 전송되지는
않습니다.

## 사용 순서

1. 로봇 메뉴에서 배포 맵 또는 저장된 RMF 프로젝트를 불러옵니다.
2. 시작 Waypoint를 선택해 Mock 로봇을 Spawn합니다.
3. 왼쪽 `작업` 메뉴를 선택합니다.
4. `새 작업`을 누릅니다.
5. 작업 유형, 배정 방식과 목적지 Waypoint를 선택합니다.
6. `작업 시작`을 누릅니다.
7. 작업 목록에서 진행 상태를 확인합니다.

작업 화면 상단에는 현재 준비 단계를 표시합니다.

```text
1단계: 배포 맵 불러오기
    ↓
2단계: 로봇 메뉴에서 로봇 Spawn
    ↓
3단계: 새 작업 생성
```

맵이나 로봇이 준비되지 않은 상태에서 `새 작업`을 누르면 아무 반응 없이 끝나지
않고, 필요한 단계와 `배포 맵 불러오기` 또는 `로봇 메뉴` 이동 버튼을 팝업으로
안내합니다.

## 작업 유형

- `이동`: 선택한 Waypoint로 이동합니다.
- `충전`: 선택한 충전 목적지로 이동합니다.
- `대기`: 선택한 대기 목적지로 이동합니다.

현재 세 유형은 목적지 이동 방식으로 실행되며, 충전량 증가나 장시간 대기 같은
후속 동작은 아직 수행하지 않습니다.

## 로봇 배정

- `자동 배정`: 현재 작업이 없는 로봇 중 배터리가 가장 높은 로봇을 선택합니다.
- 직접 지정: 사용자가 선택한 로봇에 작업을 배정합니다.

이미 다른 작업을 수행 중인 로봇에는 새 작업을 배정하지 않습니다.

## 경로 계산

현재 운영 맵의 Lane을 방향성 그래프로 변환하고 이동 거리 합이 가장 짧은 경로를
계산합니다.

- 양방향 Lane은 양쪽 방향으로 사용할 수 있습니다.
- 정방향 Lane은 시작점에서 끝점으로만 사용할 수 있습니다.
- 역방향 Lane은 끝점에서 시작점으로만 사용할 수 있습니다.
- 도달 가능한 경로가 없으면 작업을 시작하지 않고 Warning을 표시합니다.

## 작업 상태

| 상태 | 의미 |
| --- | --- |
| 대기 | 실행을 기다리는 작업 |
| 진행 중 | 로봇이 목적지로 이동 중 |
| 완료 | 목적지에 도착함 |
| 취소 | 사용자가 작업을 취소함 |
| 실패 | 작업 중 로봇이 삭제됨 |

진행 중인 작업을 취소하면 로봇은 현재 위치에서 멈추고 남은 작업 경로를
삭제합니다.

## 현재 제한사항

- 작업과 이력은 앱 메모리에만 있으며 앱 종료 시 사라집니다.
- RMF Dispatcher, 교통 스케줄 및 rmf-web에는 등록되지 않습니다.
- 여러 로봇 사이의 Lane 예약과 충돌 회피를 수행하지 않습니다.
- 실제 로봇 작업은 Fleet Adapter 및 중앙 작업 서버 연결이 추가로 필요합니다.
